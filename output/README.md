# Output

This directory contains files generated by the Financial Log Analyzer.

The output is recreated each time the pipeline runs.

## Generated Structure

```text
output/

valid_batches/
 batch1_valid.parquet
 batch2_valid.parquet
 ...

invalid_batches/
 batch1_invalid.parquet
 batch2_invalid.parquet
 ...
 anomalies.parquet
```
